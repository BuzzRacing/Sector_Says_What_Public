Features

Built for the broadcast experience

Every feature exists to make your race feel like a televised event — not a data readout with a voice on top.

⏱

Real-Time Trigger Engine

Overtakes, pit entries, fastest laps, lead changes, flag transitions, battles, and periodic race summaries — all detected from live telemetry with edge-detection and confirmation windows to prevent false calls.

🗣

Natural TTS Playback

Commentary is spoken aloud through configurable audio devices via FMOD. A queue system prevents talk-over — if the booth is hot, events are logged but audio waits its turn.

🛡

Anti-Fabrication AI

Three independent layers (system rules, per-trigger prompt templates, and post-hoc sanitizer) ensure the AI never invents tyre strategy, team radio, or collision blame. If it can't see it in the data, it doesn't say it.

🌟

Focus Driver Tracking

Pick your driver (or yourself) and the broadcast weaves their story through every callout — position changes, lap times, pit stops, momentum shifts. Matched by iRacing customer ID so it never gets confused.

📈

Live Timing Tower

Animated position changes, gap intervals, pit indicators, and DOTD standings in a glass-panel HUD overlay. Slides, flashes, and highlights just like the real F1 broadcast graphics.

🎫

Animated Race Replays

Every race is saved with lap-sample timing data. The replay animates dots on a track map, syncs commentary callouts to position, and includes full results with podium and DOTD cards.

🔧

Pit Wall Admin

Full browser-based control panel: commentator profiles and photos, prompt template editor, DOTD scoring tuning, trigger enable/disable, media gallery, track centerline editor, and race archives.

🌐

Works With Any iRacing Session

Official races, hosted sessions, AI races — anything the iRacing SDK exposes. 239 telemetry variables, all frozen once per tick for data consistency. Runs entirely local, no cloud dependency.

How It Works

From telemetry to broadcast in milliseconds

The engine reads iRacing's shared memory, detects race events, generates commentary via LLM, and speaks it through your audio device — all in a single tick loop.

1

Freeze

Snapshot all 239 telemetry variables once per tick. Every downstream read sees the same moment in time.

2

Detect

Edge-detect overtakes, pit entries, flag changes, and battles using position sort, confirmation windows, and cooldowns.

3

Generate

Send the event context to an LLM with anti-fabrication ground rules. A rotating commentator is chosen based on trigger type and location.

4

Speak

TTS converts the line to audio, FMOD routes it to your chosen device, and the commentary queue prevents talk-over.

5

Archive

Every event, lap sample, and commentary line is saved to SQLite. Race replays reconstruct the full broadcast from this data.
